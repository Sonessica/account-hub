# Folder: /src/bento

1. **Status**: Bento 卡片、画布和编辑交互模块。
2. **Logic**: 当前入口由 `editor/InfiniteCanvas.tsx` 布局与拖放，`EditorContext` 管理状态，`PersistentEditorProvider` 同步 SQLite；`widgets/` 定义卡片。
3. **Constraints**: 当前共享快照只保存一组卡片坐标；不要把旧版独立桌面/手机布局或固定列数当作主编辑器架构。

子目录：`core/` 卡片基础，`editor/` 当前编辑器与部分旧组件，`widgets/` 类型与渲染，`grid/`、`dnd/` 固定网格/旧版交互。
