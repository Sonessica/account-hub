# Folder: /src/bento/editor

1. **Status**: 当前单页 Bento 编辑器的画布、交互与持久化桥接。
2. **Logic**: `InfiniteCanvas.tsx` 负责定位、视口裁剪、平移、拖放和大图；`EditorContext.tsx` 管理卡片/资料；`PersistentEditorProvider.tsx` 读取快照并自动保存；`EditorFooter.tsx` 切换编辑和自动布局。
3. **Constraints**: 当前共享快照使用一组 `widgets`；改拖放时检查碰撞、搜索占位和多卡推挤，改保存时保留 revision 冲突处理。

其他入口：`EditorToolbar.tsx` 添加卡片，`WidgetEditorPanel.tsx`/`WidgetEditOverlay.tsx` 编辑内容，`SettingsModal.tsx` 管理个人资料，`LocationSearch.tsx` 调用 Nominatim。`EditorLayout.tsx`、设备检测等仍供旧版布局使用。
